# ثانوية المعالي الأهلية للبنين — الموقع الرسمي

موقع واجهة (Front-end) بصفحة واحدة، عربي بالكامل واتجاه RTL، مبني بـ **Vite** مع
**Three.js** لمشهد ثلاثي الأبعاد و**GSAP + ScrollTrigger** للحركات و**Lenis** للتمرير الانسيابي.

---

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير على http://127.0.0.1:5199
npm run build    # نسخة الإنتاج داخل مجلد dist/
npm run preview  # معاينة نسخة الإنتاج محلياً
```

لرفع الموقع: ارفع محتويات مجلد `dist/` إلى أي استضافة ثابتة
(Netlify أو Vercel أو GitHub Pages أو استضافة عادية) — لا يحتاج خادماً خلفياً.

### ⚠️ نقطتان تحتاجان قراراً منك

1. **حسابات التواصل**: الملصقات تكتب المعرّف `AlMaali.School`، بينما الروابط التي
   زوّدتني بها تشير إلى `almaali.s.s2012` على إنستغرام. الموقع يستخدم **الروابط التي
   أعطيتني إياها**. إن كان الحساب الصحيح مختلفاً فغيّره في `index.html`
   (يظهر في 5 مواضع: الشريط الجانبي، قائمة الجوال، المعرض، قسم التواصل، التذييل).

2. **ملف الشعار**: `public/media/logo.png` مقصوصٌ من ترويسة أحد الملصقات، لذا دقّته
   محدودة. إن أرسلت ملف الشعار الأصلي (PNG بخلفية شفافة يفضَّل) فضعه مكانه بالاسم نفسه
   وسيعمل فوراً — يظهر في شريط التنقّل وشاشة التحميل والتذييل.

## الصور والفيديو

### الصور

الصور كلها مقصوصة برمجياً من ملصقات المدرسة الثلاثة الموجودة في
`public/media/photos/` باسم `room-teaching.jpg` و`room-lab.jpg` و`room-achievements.jpg`.

لإعادة توليد كل الصور المشتقّة بعد استبدال الملصقات:

```bash
node tools/prepare-photos.mjs
```

إحداثيات القصّ مضبوطة داخل الملف لتتفادى نصوص الملصق وشرائط الإحصاءات، فإن استبدلت
الملصقات بصور جديدة عدّل الأرقام في `tools/prepare-photos.mjs`.

**الأفضل بالطبع** هو استبدال الملصقات بصور فوتوغرافية أصلية للمدرسة. عندها ضع صورك
مباشرة في `public/media/photos/` بالأسماء التي يستعملها `index.html`:
`fac-teaching.jpg` · `fac-lab.jpg` · `fac-equipment.jpg` · `fac-honours.jpg` ·
`about.jpg` · `cine-poster.jpg` · `p-yahya.jpg` · `p-abdullah.jpg` · `p-mohammed.jpg`

### الفيديو

`public/media/campus.mp4` — فيديو الجولة الذي أرسلته. الموقع يكتشفه تلقائياً:

- إن **وُجد**: يُشغَّل صامتاً داخل إطار هاتف في قسم «تعالَ وشاهد»، وزر التشغيل يفعّل الصوت.
- إن **حُذف**: تبقى صورة الغلاف وزر التشغيل ينقل الزائر إلى قسم القاعات — دون أي خطأ.

الفيديو مصوَّر عمودياً (‎478×850‎)، ولهذا صُمّم القسم بإطار هاتف بدل العرض بعرض الشاشة
الذي كان سيقصّ الصورة بشدّة. حجمه الحالي **14.5 ميغابايت** — يُفضَّل ضغطه قبل النشر:

```bash
ffmpeg -i campus.mp4 -vcodec libx264 -crf 28 -preset slow -an campus-web.mp4
```

## ربط نموذج التواصل

النموذج حالياً يتحقق من الحقول ويعرض رسالة نجاح، **لكنه لا يرسل شيئاً**.
لتفعيله، عدّل `initForm()` في [src/js/interactions.js](src/js/interactions.js)
وأرسل البيانات إلى واتساب أو Formspree أو Google Forms:

```js
// مثال: فتح واتساب برسالة جاهزة على رقم المدرسة
const text = `طلب تسجيل%0Aالاسم: ${name}%0Aالهاتف: ${phone}%0Aالصف: ${stage}`;
window.open(`https://wa.me/9647745557734?text=${text}`, '_blank');
```

## المشهد ثلاثي الأبعاد

«وسام المعالي»: ميدالية معدنية تحمل شعار المدرسة بإطار ذهبي مصقول، تطفو داخل
حلقات مدارية وغبار ذهبي وتتفاعل مع حركة المؤشّر، وتنزاح وتتلاشى مع التمرير.
الشعار يُقرأ من `public/media/logo.png` مباشرة — استبدل الملف يتغيّر الوسام.

سلوكه يتغيّر حسب حجم الشاشة:

| العرض | التموضع |
|---|---|
| ‎1280px‎ فأكثر | الوسام في يسار الشاشة بحجمه الكامل والنص إلى يمينه |
| ‎1024–1279‎ | كما سبق بحجم أصغر قليلاً |
| ‎760–1023‎ | الوسام يسار الشاشة مصغّراً وأخفّ |
| أقل من ‎760‎ | علامة مائية خافتة خلف النص، مع بقاء الغبار الذهبي |

إن تعذّر تشغيل WebGL يختفي المشهد وتبقى الواجهة كاملة وجميلة.

## ما يعمل فعلياً على الموقع

- **نموذج التسجيل** يفتح واتساب برسالة جاهزة إلى رقم المدرسة — لا يحتاج خادماً.
- **أزرار تواصل عائمة** (واتساب + اتصال) تظهر بعد مغادرة الواجهة الرئيسية.
- **زر نسخ رقم الهاتف** في بطاقة التواصل.
- **الأسئلة الشائعة** بأكورديون يفتح إجابة واحدة في كل مرّة.
- **بيانات SEO منظّمة** (Schema.org EducationalOrganization) تشمل العنوان والهاتف
  وأوقات الدوام وحسابات التواصل — تساعد ظهور المدرسة في نتائج البحث والخرائط.

## ملاحظات تقنية

- **إمكانية الوصول**: يحترم الموقع `prefers-reduced-motion` — تُختصر كل الحركات
  لمن يفعّل تقليل الحركة في نظامه.
- **بدون WebGL**: إن تعذّر تشغيل الرسوم ثلاثية الأبعاد، تبقى الواجهة كاملة وجميلة
  بالخلفيات والتدرّجات فقط.
- **التشكيل العربي**: لا نُقسّم النصوص إلى حروف أو أسطر عبر جافاسكربت، لأن ذلك
  يكسر اتصال الحروف ويُسقِط علامات التشكيل؛ نستخدم أقنعة `clip-path` بدل ذلك.
- **الاستجابة**: جرى فحص التخطيط عند ‎1440‎ و‎1024‎ و‎820‎ و‎768‎ و‎414‎ و‎360‎ بكسل —
  بلا أي تمرير أفقي، والواجهة الرئيسية تملأ الشاشة تماماً في كل حجم. وهناك قواعد
  خاصة للهاتف المستلقي (ارتفاع أقل من ‎560px‎) وللشاشات الأوسع من ‎1700px‎.
- **الفيديو**: لا يُحمَّل إلا عند اقتراب قسم الجولة من الشاشة، وإطار الهاتف بنسبة
  ‎9:16‎ تطابق الفيديو تماماً فلا يُقصّ ولا ينضغط.
- **الخطوط**: تُحمَّل من Google Fonts. لموقع يعمل دون إنترنت، نزّل الخطوط محلياً
  وعدّل الوسم في `<head>`.
